# ARON – pošta a kalendář

Veřejné informační stránky soukromých nástrojů. Verze 1.0.0.

- [Popis aplikace](https://ljanu.github.io/aron-google-pristup/)
- [Ochrana soukromí](https://ljanu.github.io/aron-google-pristup/soukromi.html)
- [Podmínky použití](https://ljanu.github.io/aron-google-pristup/podminky.html)

Pouze statické HTML. Neobsahuje zdrojové kódy nástrojů, přístupy ani uživatelská data.
Zveřejnění: GitHub Pages z větve `main`, kořen repozitáře.
